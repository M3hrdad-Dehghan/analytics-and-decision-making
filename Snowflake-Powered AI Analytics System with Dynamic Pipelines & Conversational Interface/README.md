## 🧠 Business Problem

A Canada-wide rental company collects large volumes of structured data across multiple property types, including apartments, condos, houses, and basements.  

Despite having rich datasets, extracting insights remains slow and inefficient. Business users depend heavily on technical teams to write SQL queries, limiting their ability to explore data and make timely decisions.  

This creates a gap between data availability and actionable insights.

---

## 🎯 Objective 

The objective of this project was to design and implement an end-to-end analytics solution that enables users to interact with data using natural language, eliminating the need for manual querying and accelerating insight generation.

---

## 📊 Data & Inputs

- 4 structured CSV datasets representing rental property types:
  - Apartments  
  - Condos  
  - Houses  
  - Basements  
- Features include:
  - Property attributes (bedrooms, bathrooms)  
  - Location (city / region)  
  - Listing date (time-based trends)  
  - Pricing (average rental price)  
  - Amenities (parking, pet-friendly, etc.)  
- Data stored and processed within a cloud-based data platform

---

## ⚙️ Technical Approach

- Ingested raw data into cloud storage and integrated it into Snowflake  
- Designed database, schema, and warehouse for scalable data processing  
- Transformed and cleaned data using Python and SQL into analytics-ready tables  
- Unified multi-source datasets into a single structured model for analysis  
- Performed exploratory data analysis (EDA) using SQL  
- Built a semantic layer to make data interpretable for business users  
- Enabled natural language querying using Snowflake Cortex  
- Developed a conversational interface for interactive data exploration  

---

## 🛠 Key Skills Demonstrated

- End-to-end data pipeline design (ingestion → transformation → analytics)  
- Snowflake (data warehousing, Snowpark, Dynamic Tables)  
- SQL for data transformation and analysis  
- Data modeling and schema design  
- AI-powered analytics and natural language querying  
- Streamlit for building interactive data applications  
- Cloud-based data platform integration
